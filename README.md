# merkwelt.org

Static site for Merkwelt Research, served by GitHub Pages.

- `index.html`: home
- `papers/no-neutral-worlds/`: MR-P-2026-001 (HTML, PDF, figures)
- `support.js`: page runtime (loads React from unpkg)
- `CNAME`: custom domain

New paper version: add `no-neutral-worlds-vX.Y.pdf` beside the old one, and add a row to the versions list.
